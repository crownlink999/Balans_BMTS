# input

Сюда кладутся Excel-файлы. После загрузки сайт обновится сам (1–3 минуты):

* файл баланса БМТС (книга с листами «баланс», «поступление (вне баланса)», «выдача (МТ)», «баланс+поступление-выдача МТ», «баланс Цехов (Virtual)»);
* файл ME2N (первый лист с колонкой «Год плана закупа»).

Имя файла не важно, вид определяется по содержимому. Если файлов одного вида несколько, берётся самый свежий.
Можно загружать только один из двух файлов: вторая часть останется прежней.
